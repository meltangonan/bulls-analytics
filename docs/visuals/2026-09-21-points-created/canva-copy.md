Definition: Points created = points scored + points from assisted baskets.

Handle: @chicagobullsdata

Column explanation for the brief: NBA rank is the rank in total points created
across that season's league. Team percentage uses Chicago's full-season points;
individual player shares overlap. Created per game uses the player's games played.
MVP labels show final voting placement only when the player received votes.
