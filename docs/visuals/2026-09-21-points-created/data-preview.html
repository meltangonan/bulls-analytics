Sources and checks

Bulls totals: saved NBA.com scoring and play-by-play, with all 543 player-season assist counts reconciled. League rank: official NBA scoring plus Basketball Reference play-by-play assist points for the complete league; traded players counted once using full-season totals. Competition rank, with ties sharing rank.

Four selected player-seasons have assist-point differences of 2–3 between NBA play-by-play and Basketball Reference (Jordan/Pippen 1996–97; Butler 2015–16 and 2016–17). Bulls values retain NBA counts; none of these changes the displayed league placement. A separate pbpstats comparison confirms 13 selected ranks across 10 complete league seasons with no differences. Its 500-player-limited responses for 2020–21 and 2025–26 were excluded from that check.

Rose 2010–11: 2,026 + 1,409 = 3,435; 3,435 / 81 = 42.4 per game; 3,435 / 8,087 Bulls points = 42.5%; NBA rank 1.
