# Player headshots

These ten player cutouts were copied from the project's shared NBA headshot cache for this post's reproducible render. The source pattern is `https://cdn.nba.com/headshots/nba/latest/1040x760/<NBA player ID>.png`; the NBA serves current portraits, which may show a jersey from a different season or team than the winning Bulls season. Each saved image has a transparent background and was visually checked in the two-page draft.
